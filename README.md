# crypto
加解密库

## 子包

| 包      | 说明                                                          |
|--------|-------------------------------------------------------------|
| `aes`  | AES 加解密（CBC、ECB、GCM 等）                                      |
| `des`  | DES / 3DES 加解密                                              |
| `sm2`  | 国密 SM2 椭圆曲线公钥密码算法（GB/T 32918），签名验签 + 公钥加解密                   |
| `sm3`  | 国密 SM3 杂凑算法（GB/T 32905-2016），实现 `hash.Hash`                 |
| `sm4`  | 国密 SM4 分组密码算法（GB/T 32907-2016），实现 `cipher.Block`，含 ECB/CBC 模式 |
| `xpem` | PEM 编解码                                                     |
| `xrsa` | RSA 加解密、签名验签                                                |

国密三件套（sm2/sm3/sm4）零外部依赖，仅使用 Go 标准库，并通过国标附录标准数据
与跨实现已知答案（KAT）单测校验。
